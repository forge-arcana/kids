# Kids Coding Workspace

A safe, guided workspace template for kids to learn coding with Claude Code.

## Prerequisites

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) installed

## Setup

1. Copy this folder into a new directory for your child
2. Open it in Claude Code
3. Tell Claude: **"Set up my kid's profile"**
4. Claude will ask for your child's name, age, and interests — then suggest a starter project
5. Hand it over to your kid and let them start building

## Updating

When this template gets new guardrails or improvements:

1. Copy the new `CLAUDE.md` into your child's workspace (overwrite the old one)
2. `child-profile.md` is your child's data — never overwrite it

That's it. New rules apply immediately. Your child's profile and projects stay intact.

## What's Inside

| File | Purpose |
|------|---------|
| `CLAUDE.md` | Guardrails and rules Claude follows (the template — update this) |
| `child-profile.md` | Your child's profile, progress, and learnings (their data — don't overwrite) |
